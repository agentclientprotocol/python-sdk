# Use Cases

Projects using the ACP Python SDK in production. For the broader protocol directory across languages, visit [agentclientprotocol.com](https://agentclientprotocol.com/).

## Agents

| Project | Highlights |
| --- | --- |
| [MoonshotAI/kimi-cli](https://github.com/MoonshotAI/kimi-cli) | CLI-first ACP+MCP coding agent showcasing streamed updates, permission prompts, and tool call UX. |
| [MiniMax-AI/Mini-Agent](https://github.com/MiniMax-AI/Mini-Agent) | Minimal single-agent reference implementation demonstrating a complete ACP execution loop. |
| [OpenHands/OpenHands-CLI](https://github.com/OpenHands/OpenHands-CLI) | Interactive CLI interface for the OpenHands coding agent over ACP. |
| [evalstate/fast-agent](https://github.com/evalstate/fast-agent) | Framework for defining, prompting, and testing MCP-enabled agents and workflows. |
| [bubbuild/bub-contrib (`bub-acp-server`)](https://github.com/bubbuild/bub-contrib) | ACP server bridge exposing Bub agents to editors and desktop orchestrators. |

## Clients

| Project | Highlights |
| --- | --- |
| [wiki3-ai/agent-client-kernel](https://github.com/wiki3-ai/agent-client-kernel) | Jupyter kernel speaking ACP so notebooks can interact with external agents. |
| [OhadRubin/simple-acp-client](https://github.com/OhadRubin/simple-acp-client) | High-level Python client wrapper for driving ACP agent executables. |
